# Dr. Ben Zhang Academic Homepage

This is an English academic homepage draft generated from `CV_Dr.Ben Zhang.docx`.

## Template Note

The site structure follows common GitHub academic homepage patterns, especially the section logic used by the public `academicpages/academicpages.github.io` project:

- profile hero
- research interests
- selected publications
- appointments and education
- awards and academic service
- media-ready gallery area
- contact links

GitHub cloning was unavailable during setup, so this draft is implemented as a lightweight static site instead of a direct template clone. It is ready for GitHub Pages because it only uses `index.html`, `styles.css`, and `script.js`.

## How to Preview

Open `index.html` directly in a browser, or serve this folder with any static server.
